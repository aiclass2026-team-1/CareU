## 2. 畫面職責與視覺保留要求

### 2.1 畫面核心職責
- 傳達「溫暖出現、健康逐漸清晰、陪伴與守護」之品牌印象。
- 建立主 Slogan「Care U．為你的健康導航」。
- 在不增加使用者負擔下平滑過渡至首頁。

### 2.2 視覺規格保留 `[CODE_OBSERVED]`
- **Logo 結構**：定案藍色 U 型 (`#197AFC`)、中央藍色十字、暖橘色圓點 (`#FB8F54`)。
- **Logo 尺寸**：響應式寬度 `width: clamp(119px, 16.2vw, 176px);`，內容垂直居中略微向上調整約 `1vh`。
- **品牌文字**：`Care U．為你的健康導航`（使用網頁文字呈現，深藍色 `#07295C`，不使用副標）。
- **字型策略（`[CONFIRMED]` DEC-03）**：維持系統無襯線字體宣告 `"Noto Sans TC", "PingFang TC", "Microsoft JhengHei", system-ui, sans-serif`。
- **背景與版面**：全螢幕滿版 `100svh`，頁面底色 `#F7F8FA`，禁止捲動。

## 3. 動畫時序、輸入操作與條件分支

### 3.1 動畫時序規格 `[CODE_OBSERVED]`
| 動畫階段 | 開始延遲 | 持續時間 | 視覺效果 |
| :--- | :---: | :---: | :--- |
| **藍色 Logo 清晰化** | `0.28s` | `1.28s` | 透明度由 `0.18` 提高至 `1`，模糊度由 `15px` 降至 `0`。 |
| **暖橘圓點升起** | `0.34s` | `1.14s` | 圓點自水平線下緣（`y=180.334`）使用固定 clipPath 向上浮現。 |
| **品牌文字淡入** | `1.58s` | `0.66s` | 文字由向下 `8px` 向上微移並由透明度 `0` 淡入至 `1`。 |
| **自動觸發進入首頁** | `2.85s` (2850ms) | — | 呼叫進入首頁函式。 |
| **入口頁淡出** | — | `0.44s` | 頁面整體淡出（`.is-leaving`），首頁淡入。 |

### 3.2 使用者操作與略過分支
- **主動略過**：點擊螢幕任意位置、觸控點擊、鍵盤按下 `Enter` 或 `Space` 鍵，立即中斷計時並略過動畫進入首頁。
- **防重複跳轉**：進入流程開始後立即鎖定狀態，避免連點觸發多次跳轉。
- **無動態模式 (`prefers-reduced-motion: reduce`)**：不播放升起與模糊動畫，直接顯示完整靜態 Logo 與文字，**取消 2.85s 自動跳轉**，等待使用者主動點擊進入。

## 4. 原型行為 vs 工程化目標區分

| 項目 | 原型現況 `[CODE_OBSERVED]` | 正式工程化目標 `[PROPOSED]` |
| :--- | :--- | :--- |
| **首頁銜接** | 切換至原型內嵌 `#home` 占位層 | 使用 Vue Router 執行 `router.replace('/home')` |
| **重新播放** | 提供 `#replay` 按鈕在同頁重播 | 移除重播按鈕；正式路由跳轉至 `/home` |
| **進場計時器** | `window.setTimeout(enterHome, 2850)` | 封裝於 `LogoIntro.vue` 生命週期，銷毀時自動清理 |

## 6. 逐項驗收條件清單

- [ ] Logo 造型、比例、SVG ViewBox（`0 0 500 630.018`）與品牌色彩完全相符。
- [ ] 圓點自水平線遮罩升起，無彈跳或縮放變形。
- [ ] 品牌文字為「Care U．為你的健康導航」，顏色為 `#07295C`。
- [ ] 點擊、觸控、Enter、Space 均可立即略過動畫。
- [ ] 動畫正常播放約 2.85 秒後平滑轉入 `/home`。
- [ ] `prefers-reduced-motion: reduce` 下顯示靜態版且不自動跳轉。
- [ ] 頁面禁止捲動，無水平或垂直溢出捲軸。
- [ ] **`[RUNTIME_UNVERIFIED]`**：真機行動裝置（iOS/Android）由 Splash 轉入 Home 的無縫轉場流暢度。
